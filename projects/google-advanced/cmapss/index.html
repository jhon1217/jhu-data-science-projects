How many useful cycles does an engine have left?

A machine learning case study that turns multivariate sensor histories into remaining useful life estimates for a fleet of simulated turbofan engines.

What drives the model?

Grouped feature importance combines each sensor's current level, five-cycle mean, and one-cycle change.

Approach

From sequence data to a maintenance signal

  1. Calculate capped remaining life for every training cycle.
  2. Remove constant sensors and rank the remaining signals by association with the target.
  3. Add recent change and five-cycle rolling means to capture degradation.
  4. Hold out the final 20 engines for development validation, then evaluate on NASA's separate test fleet.
Decision use

Prioritize inspection, with context

The estimate can rank engines for closer attention and expose which sensor patterns informed that priority. It should support maintenance planning alongside engineering thresholds, inspection history, and the cost of early versus late intervention.

The FD001 subset represents one operating condition and one fault mode, so results should not be generalized to every fleet without new validation.

Source: NASA C-MAPSS Jet Engine Simulated Data, subset FD001. Model results are generated by the reproducible Python project.
